# 👋 Saudação Personalizada

Projeto desenvolvido para praticar entrada de dados, manipulação de variáveis e operações básicas.

## 📋 Enunciado

> Escreva um código que receba o nome e o ano de nascimento de alguém e imprima na tela a seguinte mensagem: **"Olá 'Fulano' você tem 'X' anos"**

---

## ⚙️ Funcionalidades

* Recebe o nome do usuário via entrada padrão (teclado).
* Recebe o ano de nascimento do usuário.
* Calcula a idade com base no ano atual.
* Exibe a mensagem formatada com o nome e a idade calculada.

---

## 🖥️ Exemplo de Uso

**Entrada:**
```text
Digite seu nome: João
Digite seu ano de nascimento: 2000
```

**Saída:**
```text
Olá João você tem 26 anos
```
